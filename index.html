Claude Workspace MCP - Personal

This is a private, single-owner Google OAuth application. It is not offered to the public and does not accept sign-ups.

It lets the owner's own Claude Desktop installation work with the owner's own Google accounts (Gmail, Drive, Docs, Sheets, Slides, Calendar, Tasks, Contacts) through the open-source Google Workspace MCP server, running locally on the owner's computer.

Gmail access is limited to reading, organizing and drafting. The app does not request permission to send email.
